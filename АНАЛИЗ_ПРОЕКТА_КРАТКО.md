# KronaERP — ПОЛНЫЙ АНАЛИЗ ПРОЕКТА (ДЛЯ НЕЙРОСЕТИ)

## 1. ОБЩЕЕ

**Тема:** Android-приложение учёта заказов мебельной фабрики
**Стек:** Kotlin 2.0.21, Jetpack Compose + Material3, Dagger Hilt 2.57.1, Firebase (Auth, Firestore, Storage, FCM), Navigation Compose 2.9.8 + Kotlin Serialization, Coil 2.7.0
**Архитектура:** Multi-module MVVM + Repository + Hilt DI
**Min SDK:** 24, **Target:** 36
**Пакет:** com.example.kronaerp

---

## 8. НАВИГАЦИЯ

```
KronaAppNavigation (читает navigationState)
  ├── Loading -> CircularProgressIndicator
  ├── Auth -> AuthGraph (LogInScreen <-> RegisterScreen)
  ├── Client -> ClientGraph (MyOrders -> OrderDetail, NewOrder, ChatList -> ChatThread, Profile)
  └── Manager -> ManagerGraph (Dashboard, Clients -> UserDetail, Orders -> OrderDetail, ChatList -> ChatThread, Statistics, Profile)
```

**AppNavigationViewModel:** проверяет FirebaseAuth.currentUser -> Firestore users/{uid}.role -> NavigationState
**Типобезопасные маршруты:** sealed interface + @Serializable

## 10. DATA FLOW

```
Composable (collectAsStateWithLifecycle)
  -> ViewModel (StateFlow, viewModelScope.launch)
    -> Repository (callbackFlow, addSnapshotListener)
      -> Firestore Firestore
```

**Фотографии:** сохраняются в Firestore как Base64 строки в поле `imageUrls: List<String>`. На клиенте декодируются через `BitmapFactory.decodeByteArray` → `asImageBitmap()` → `Image(bitmap = ...)`.
